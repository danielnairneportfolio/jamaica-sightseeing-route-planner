# Jamaica Sightseeing Route Planner

## Project Overview

This project was developed as part of undergraduate Information Technology coursework.

The Jamaica Sightseeing Route Planner is a C++ console-based application designed to simulate travel routes between selected Jamaican parish capitals.

The application uses graph data structures and algorithms to represent connected locations, calculate shortest paths, and explore sightseeing routes.

## Features

- **Shortest Path Calculation:** Uses Dijkstra's algorithm to determine the shortest route between two locations in the predefined graph.
- **Adjacent Location Suggestions:** Displays neighboring locations and their distances.
- **Graph Visualization:** Prints an adjacency list showing the connections between locations.
- **Greedy Sightseeing:** Generates a sightseeing sequence based on a greedy selection strategy.
- **Interactive Menu:** Allows users to select operations through a command-line interface.
